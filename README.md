This project is a web page to upload videos to a list.

Purpose: Learn Software Development working on a real project.

Currently it only has HTML,CSS and JS files, I didn't use a framework yet.

Main Branch -> The web page where in the "Anime Openings Main List" section you can upload, edit and delete videos.The videos are stored using IndexedDB (JS API). Even if you leave
you won't lose your data because IndexedDB stores data in the navigator. The videos are shown in a column ordered by position. You can upload any video type, the "Anime Openings Main List"
is an example of use. The elements shown are the title, position and a thumbnail that if you click it, it goes to the video link.

Static Branch -> You can see and old version of the Main Branch where there are elements hardcoded in the HTML file, so there is an example of how the page looks if you have a lot of videos
uploaded.
